Steps for Telegram Notification:-

1. Create a Telegram Bot:

    * Open Telegram on your phone or PC
    * Search for @BotFather in the search bar
    * Click on it and press Start
    * Send this message: /newbot
    * BotFather asks: "What's the name of your bot?" — type any name: HydroWatch Alert Bot
    * BotFather asks: "What's the username?" — must end with bot: hydrowatch_alerts_bot
    * Copy and save this token!

2. Get Your Chat ID:

    * Search for your bot username in Telegram (e.g. @hydrowatch_alerts_bot)
    * Click Start on your bot
    * Send any message to your bot: hello
    * Now open this URL in your browser (replace YOUR_TOKEN): https://api.telegram.org/botYOUR_TOKEN/getUpdates
    * You will see a JSON response — find "id" inside "chat":

        {
        "message": {
            "chat": {
            "id": generated_id,    ← THIS IS YOUR CHAT ID
            "first_name": "Nivesh"
            }
        }
        }
    
    * Copy that number — that is your Chat ID!**

3. Test the Bot Works

    * Paste this in your browser (replace TOKEN and CHAT_ID): https://api.telegram.org/botYOUR_TOKEN/sendMessage?chat_id=YOUR_CHAT_ID&text=HydroWatch+Connected!
    * You should instantly receive "HydroWatch Connected!" message on Telegram. ✅

4. Add to Your Project
    * Open docker\docker-compose.yml: docker\docker-compose.yml
    * Find the backend environment section and update:

        environment:
            DATABASE_URL:       postgresql://hydrowatch_user:hydrowatch_pass@db:1234/hydrowatch
            SECRET_KEY:         hydrowatch-secret-key-2026
            TELEGRAM_BOT_TOKEN: generated_token
            TELEGRAM_CHAT_ID:   generated_id
    * Save and close.

5. Test Alert from CMD
    
    curl "https://api.telegram.org/botYOUR_TOKEN/sendMessage?chat_id=6231470713&text=HydroWatch+Test+Alert+Working!"

    * Press Y then Enter to continue.
    * You should see a response like:

        StatusCode        : 200
        StatusDescription : OK

    * And you will receive the message instantly on Telegram! ✅

Complete Docker Commands Used - Terminal or CMD: 

1. Navigate to project: cd D:\6TH SEMESTER\DEVOPS\IA3\CODE\hydrowatch\hydrowatch

2. Create missing folder: mkdir ml\models

3. Fix ML requirements (scikit-learn version): (
echo numpy==1.26.4
echo pandas==2.2.1
echo scikit-learn==1.4.1.post1
echo matplotlib==3.8.2
echo seaborn==0.13.2
echo joblib==1.3.2
) > ml\requirements_ml.txt

4. Build all Docker images: docker compose -f docker\docker-compose.yml build

5. Start all containers: docker compose -f docker\docker-compose.yml up -d

6. Check container status: docker compose -f docker\docker-compose.yml ps

7. Check logs (frontend was crashing): docker logs hydrowatch-frontend

8. Find process using port 8000: netstat -ano | findstr :8000

9. Kill processes blocking port 8000:taskkill /PID 11124 /F
                                     taskkill /PID 10140 /F

10. Stop all containers: docker compose -f docker\docker-compose.yml down

11. Restart all containers (after fixing docker-compose.yml): docker compose -f docker\docker-compose.yml up -d

12. All 8 containers started successfully! Now open your app: start http://localhost:3000

13. Also open these to verify everything works: start http://localhost:8000/docs
                                                start http://localhost:3001

    start http://localhost:3001/d/hydrowatch-main/hydrowatch-infrastructure-dashboard
